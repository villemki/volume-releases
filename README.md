# Volume

A fast media library for Google Drive on macOS, with your Drive in Finder for apps and agents.

**[Download the latest version](https://github.com/villemki/volume-releases/releases/latest)** (macOS 26 or later)

## Install

1. Download `Volume-<version>.zip` from the latest release and open it.
2. Move **Volume** to your Applications folder and open it.
3. macOS says it can't verify Volume. Click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway**. (Only the first time.)
4. Sign in with Google. If Google says the app isn't verified, choose **Advanced → Go to Volume**.
5. To use your Drive in Finder, click **Open in Finder** in Volume, then **Enable** in the Finder window.

Volume updates itself. This repository hosts the downloads and the update feed.
